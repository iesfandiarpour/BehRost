# سایت بهرست

## اجرا (اولین بار)
1. Node.js نسخه‌ی LTS را از nodejs.org نصب کنید.
2. در پوشه‌ی `site` این دستورها را بزنید:
   - `npm install`
   - `npm run setup` (ساخت تنظیمات، دیتابیس و محتوای اولیه؛ رمز ادمین را همین‌جا نشان می‌دهد)
   - `npm run dev` و بعد باز کردن http://localhost:3000

## پنل مدیریت
آدرس: `/admin` (در مرحله‌ی ساخت پنل اضافه می‌شود). نام کاربری و رمز اولیه در فایل `.env.local` است. رمز را به کسی ندهید و بعد از ورود عوضش کنید.

## پشتیبان‌گیری
همه‌ی اطلاعات سایت (محصولات، سفارش‌ها، مقاله‌ها، پیام‌ها) در فایل `data/app.db` است و عکس‌های آپلودشده در پوشه‌ی `uploads/`. از این دو پوشه نسخه‌ی پشتیبان بگیرید.

## قیمت‌ها
قیمت‌های اولیه‌ی محصولات فقط نمونه‌اند. قبل از انتشار از پنل مدیریت با قیمت واقعی عوض کنید.
